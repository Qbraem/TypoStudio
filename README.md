# Typo Studio

Maak transparante typografie-PNG's voor Instagram (Morning Coffee, Coffee Break, …).
Kies uit categorieën, pas tekst/lettertype/kleur aan, of laat Claude nieuwe ontwerpen maken.

## Draaien

```
npm start
```

## Instellingen (omgevingsvariabelen)

| Variabele | Nodig? | Uitleg |
|---|---|---|
| `ANTHROPIC_API_KEY` | voor de ✨ AI-generator | Sleutel van console.anthropic.com. Zonder sleutel werkt de rest gewoon. |
| `APP_PIN` | aangeraden | Pincode die gevraagd wordt voor de AI-generator, zodat vreemden je sleutel niet gebruiken. |
| `ANTHROPIC_MODEL` | nee | Standaard `claude-sonnet-5-5`. |

Eigen ontwerpen worden bewaard in de browser van het toestel.
